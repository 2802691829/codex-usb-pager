# 屏幕凸起卡槽与六边形视窗对齐设计

日期：2026-07-29

## 问题与根因

当前前壳使用 `27.1 mm` 的六边形对边尺寸。该正六边形采用上下顶点
朝向，因此上下顶点距离为：

`27.1 / (sqrt(3) / 2) = 31.29 mm`

该开口高于屏幕凸起部分的 `29 mm` 高度，并且以外壳/显示有效区中心
定位，没有从屏幕凸起顶部建立基准。因此六边形超出屏幕平面，屏幕卡槽
也表现为按旧的近似玻璃尺寸固定，而不是卡住实际屏幕凸起。

## 已确认的实物尺寸

- 屏幕凸起部分：宽 `26.0 mm`、高 `29.0 mm`。
- 屏幕凸起四周有 `0.5 mm` 黑边，外观上不得从前壳视窗露出。
- 屏幕凸起底部有 `3.0 mm` 非显示区域，六边形视窗不得保留在该区域。
- 六边形上下顶点距离：`23.5 mm`。
- 卡槽采用方案 1：屏幕凸起四周单边装配间隙 `0.15 mm`。

PCB 的 `27.78 × 39.22 mm` 外形和四个 `Ø2 mm` 定位孔继续用于定位柱，
但不再作为屏幕卡槽和六边形视窗的外形基准。

沿用规格图中屏幕凸起顶部距 PCB 顶边 `5.00 mm` 的定位尺寸。将屏幕凸起
高度改为实测 `29.00 mm` 后，其底边距 PCB 底边为
`39.22 - 5.00 - 29.00 = 5.22 mm`。

## 屏幕凸起卡槽

卡槽内包络为：

- 宽：`26.0 + 2 × 0.15 = 26.30 mm`
- 高：`29.0 + 2 × 0.15 = 29.30 mm`

卡槽的前端承托平面与屏幕凸起正面平行并贴合，使屏幕凸起进入卡槽后
由前壳内面确定 Z 向位置。四根 PCB 定位柱保留，负责孔位对中；卡槽负责
约束屏幕凸起的 X/Y 外形。左右压片继续从背面压住屏幕凸起，但不得进入
六边形可视开口，也不得与蜂鸣器 `Ø12 × 11.5 mm` 净空相交。

屏幕凸起正面和卡槽承托平面均使用前壳内面
`Z = front_seam_z = 2.30 mm` 作为装配基准。`2.0 mm` 的屏幕凸起厚度
从该平面向后壳方向延伸；不得用 PCB 正面或背面替代这个承托基准。

卡槽不得以 PCB 的 `27.78 × 39.22 mm` 外框生成，也不得将 PCB 整体夹紧
在玻璃/屏幕凸起卡槽内。

在现有坐标系中，PCB 中心 Y 为 `-1.64 mm`，因此：

- PCB 顶边 Y：`-1.64 + 39.22 / 2 = 17.97 mm`
- 屏幕凸起顶边 Y：`17.97 - 5.00 = 12.97 mm`
- 屏幕凸起中心 Y：`12.97 - 29.00 / 2 = -1.53 mm`

卡槽中心使用 `(X, Y) = (0.00, -1.53) mm`，不再直接复用 PCB 中心。

## 六边形视窗

六边形保持正六边形、上下顶点朝向：

- 上下顶点距离：`23.50 mm`
- 左右对边距离：`23.50 × sqrt(3) / 2 = 20.35 mm`

比例约束的含义是六边形自身保持正六边形、Blossom 外形继续按原 SVG
等比生成，二者均不得沿单一轴拉伸。Blossom 外壳目标宽度保持
`56.0 mm`；只把独立六边形切口等比缩放到 `23.50 mm` 上下顶点距离，
不把整个外壳缩小到无法容纳屏幕 PCB 的尺寸。

定位使用屏幕凸起顶部，而不是 PCB、外壳或旧显示有效区中心：

1. 屏幕凸起顶部为 Y 向基准。
2. 六边形上顶点位于屏幕凸起顶部向下 `0.50 mm`，遮住顶部黑边。
3. 六边形下顶点位于上顶点向下 `23.50 mm`。
4. 屏幕凸起底边距六边形下顶点：
   `29.0 - 0.5 - 23.5 = 5.0 mm`。

因此底部 `3.0 mm` 非显示区、底部 `0.5 mm` 黑边以及额外 `1.5 mm`
遮挡余量均位于前壳覆盖区内，不会从六边形视窗露出。

横向以 `26.0 mm` 屏幕凸起中心对齐。六边形左右对边仅宽 `20.35 mm`，
每侧覆盖余量为 `(26.0 - 20.35) / 2 = 2.825 mm`，大于 `0.5 mm`
黑边宽度。

对应现有外壳坐标：

- 六边形上顶点 Y：`12.97 - 0.50 = 12.47 mm`
- 六边形中心 Y：`12.47 - 23.50 / 2 = 0.72 mm`
- 六边形下顶点 Y：`0.72 - 23.50 / 2 = -11.03 mm`

六边形中心使用 `(X, Y) = (0.00, 0.72) mm`，不得再次居中到外壳原点。

六边形切口只贯穿前壳显示窗口所需厚度，并在屏幕凸起正面平面终止；
不得延伸到 PCB 平面，也不得切坏卡槽、定位柱、压片或隐藏卡扣。

## 保持不变的结构

- USB 后开孔尺寸、圆角和位置。
- 蜂鸣器 `Ø12 × 11.5 mm` 内部净空及无声孔设计。
- 前壳刚性公扣、后壳弹性母扣和指甲拆卸凹位。
- 前后壳 Blossom 凹凸高度差 `1.5 mm`。
- Blossom 外形目标宽度 `56.0 mm`，SVG 等比缩放，不拉伸。
- 四个 PCB 定位柱的孔位基准。

## 自动验收

1. 参数检查：
   - 六边形上下顶点距离为 `23.50 mm`。
   - 六边形左右对边距离为 `20.35 mm`，允许计算舍入误差 `±0.01 mm`。
   - 屏幕凸起包络为 `26.0 × 29.0 mm`。
   - 卡槽内包络为 `26.30 × 29.30 mm`。
2. 位置检查：
   - 六边形上顶点距屏幕凸起顶部 `0.50 mm`。
   - 六边形下顶点距屏幕凸起底部 `5.00 mm`。
   - 六边形与屏幕凸起横向中心一致。
   - 屏幕凸起顶边距 PCB 顶边 `5.00 mm`，卡槽中心 Y 为 `-1.53 mm`。
   - 六边形中心 Y 为 `0.72 mm`。
   - 屏幕凸起正面与卡槽承托面同位于 `Z = 2.30 mm`。
3. 几何检查：
   - 六边形切口完全位于屏幕凸起投影内。
   - 卡槽与六边形切口、定位柱、压片的实体关系正确。
   - 屏幕、USB、蜂鸣器及卡扣实体干涉体积均为 `0`。
   - 前壳和后壳均保持单一有效实体。
4. 回归检查：
   - 现有卡扣咬合、活动间隙、蜂鸣器间隙和 USB 开口契约继续通过。

## 人工验收视图

- 前壳正面正投影：六边形上顶点从屏幕顶部黑边内侧开始，四周不露黑边，
  底部不露 `3 mm` 非显示区。
- 前壳内面正投影：能看到 `26.30 × 29.30 mm` 屏幕凸起卡槽、四根 PCB
  定位柱和左右压片，且卡槽不再沿 PCB 外框生成。
- 屏幕装配剖面：屏幕凸起正面与前壳承托平面贴合，PCB 位于卡槽后方，
  六边形切口不延伸到 PCB 平面。
