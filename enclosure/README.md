# Blossom 外壳输出说明

`outputs/` 根目录保存已确认的只读基线；本次四卡扣改造全部位于
`outputs/four-latch-retrofit/`，不会覆盖基线文件。

## 最终文件

- `blossom-enclosure.FCStd`：可编辑 FreeCAD 源模型。
- `blossom-enclosure.step`：前壳与后壳组合交换模型。
- `blossom-front.stl`：前壳树脂打印网格。
- `blossom-rear.stl`：后壳树脂打印网格。
- `audit.json`：尺寸、装配避让和网格完整性审计。
- `review-dimensions.txt`：关键尺寸摘要。
- `review-*.png`：外观、内部、屏幕退让、四卡扣和三段装配复核图。

只有 `audit.json` 中 `passed` 为 `true`，并且所有 `checks` 均为 `true` 时，
两份 STL 才可作为打印候选。

## 合盖顺序

1. 将上方两个公头倾斜插入后壳上方接收槽。
2. 放平前壳。
3. 从底边向上滑动 `2.50 mm`，直到下方两个卡扣进入 `0.25 mm` 浅止动。

屏幕由后壳内陷支撑和四个边缘止挡固定，正面不设屏幕卡槽。USB 开口相对
基线向上移动 `5.00 mm`。蜂鸣器完全内置，本版本不增加蜂鸣器开孔。

## 嘉立创树脂打印

- 建议倾斜摆放，避免把正反 Blossom 浮雕和正面六边形承靠边直接贴平台。
- 支撑尽量落在隐藏内表面，避开屏幕承靠面、四个卡扣受力面和滑动导轨。
- 普通壳壁为 `1.50 mm`；卡扣根部和导轨受力壁不低于 `1.30 mm`；已知薄片、
  桥和止挡不低于 `0.80 mm`。
- 清洗、排液并完全固化后再试装。首次合盖应缓慢滑入，不要在未固化树脂上
  强行按压卡扣。
