# Codex USB Pager GitHub 完整发布设计

日期：2026-09-27

## 目标

把 Codex USB Pager 的程序与最终外壳模型整理到同一个独立 GitHub 仓库，
为后续下载、维护、构建、烧录和树脂打印提供一份清晰、可复现的发布源。

## 仓库设置

- 仓库名：`codex-usb-pager`
- 默认可见性：私有
- 默认分支：`main`
- 本地独立仓库：`C:\Users\28026\Documents\saltyfish\codex-usb-pager-github`
- 不上传原始 `saltyfish` 工作区中的其他项目。

## 内容结构

程序文件保持当前独立仓库结构不变，包括：

- RP2040-Zero 固件源码、测试和已验证 UF2；
- 主机端事件聚合、USB 通信、周余量读取和测试；
- Blossom 图形资源和程序设计历史；
- 程序交接说明与已安装 Hook 快照。

新增 `enclosure/`，只收录最终四卡扣外壳版本：

- `enclosure/cad/`：参数、建模、渲染和审计脚本；
- `enclosure/tests/`：外壳几何与源码约束测试；
- `enclosure/outputs/`：FreeCAD 源文件、STEP、前后壳 STL、`audit.json`、
  尺寸摘要和复核图；
- `enclosure/docs/`：最终外壳相关设计与实施文档。

旧基线外壳、旧 ZIP、构建缓存、Python 缓存、临时测试目录、对象文件和
重复输出不进入仓库。

## README

根目录 `README.md` 使用中文，按实际使用顺序说明：

1. 项目用途与仓库目录；
2. RP2040-Zero、屏幕、蜂鸣器接线；
3. USB 状态协议和屏显/蜂鸣器行为；
4. 直接使用已验证 UF2 的烧录步骤；
5. 从源码构建固件的方法；
6. 主机端工具的安装、启动与验证；
7. 最终四卡扣外壳文件选择、树脂打印建议和合盖顺序；
8. 测试命令、维护入口和已知环境注意事项。

README 不声称未重新验证的功能已经通过测试，并明确外壳输出必须以
`audit.json` 中 `passed=true` 且所有检查为真作为打印候选条件。

## 验证与安全

上传前执行以下检查：

- 文件清单与目录结构检查；
- 密钥、令牌、密码和私钥模式扫描；
- Git 暂存差异与工作区状态检查；
- 外壳审计结果读取与关键输出存在性检查；
- README 中的路径和命令与实际仓库一致性检查。

本任务不修改固件、主机端业务逻辑或外壳几何，不烧录设备，也不删除原始
工作区文件。

## 发布流程

1. 在本地独立仓库加入最终外壳文件并更新 README；
2. 完成验证后提交到 `main`；
3. 用户在 GitHub 完成一次登录；
4. 创建私有仓库 `codex-usb-pager`；
5. 配置 `origin` 并推送 `main`；
6. 打开仓库页面，核对 README 和文件目录可见。
